# ADR-007: Delivery process

Status: Proposed

## Context
Every new feature must be approved and verified before delivery.

## Decision
Research, Analysis, Design (UX/UI confirmed first), ADR, Develop, Verify, Deliver for every piece of work. ADRs live in docs/adr. Very small changes use a one-page Feature Decision Note.

## Consequences
A little more time per feature; every decision is traceable.
