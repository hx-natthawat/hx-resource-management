# ADR-001: Build vs Buy

Status: Proposed

## Context
SaaS tools (Runn, Float) work immediately; Planview and Kantata are heavy. HarmonyX shares people across subsidiaries, must integrate internal systems, and may productise the system for government and enterprise clients.

## Decision
Build in-house at the smallest MVP scope, designed to become a product. Fallback: a one-quarter Runn pilot applying ADR-002 to ADR-004.

## Consequences
Own the IP and data model. About 8 weeks before real use, and a team must maintain it.
