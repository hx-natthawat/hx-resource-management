# HX Resource Management · Prototype

ต้นแบบที่ใช้งานได้จริงของระบบบริหาร Resource ของ HarmonyX สร้างจาก UX/UI ที่ได้รับอนุมัติแล้ว ออกแบบแบบ Mobile First และใช้เสียงเป็นช่องทางหลัก

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 บนมือถือหรือย่อหน้าต่างให้แคบ ควรใช้ Chrome หรือ Edge เพราะสองเบราว์เซอร์นี้รองรับการพูดภาษาไทย

## ลองเส้นทางหลัก (ประมาณ 1 นาที)

1. กดไมค์สีทองแล้วพูด หรือกดประโยคตัวอย่าง "ขอ architect ... ให้ CRM ภาครัฐ ..."
2. ระบบถามเฉพาะช่องที่ขาด ตอบว่า "ซีเนียร์ เน้น AWS ด้วย"
3. กด "ตรวจและอนุมัติ" ตรวจช่องที่มีพื้นสีทอง (ระบบตีความ) แล้วกด "อนุมัติและส่ง"
4. เปลี่ยนบทบาทเป็น Resource Manager แล้วไปที่ "อนุมัติ" ระบบแนะนำคนที่ว่างพอ กด "อนุมัติ (Hard)"
5. ไปที่ Conflict ระบบเลือกทางแก้ตาม Rank ไว้ให้ กด "บันทึกการตัดสิน" แล้วดูผลใน Decision log

ข้อมูลทั้งหมดเป็นข้อมูลตัวอย่างและเก็บในหน่วยความจำเท่านั้น รีเฟรชหน้าเมื่อใดข้อมูลจะกลับไปเป็นค่าเริ่มต้น
