# ADR-003: Conflict resolution rule

Status: Proposed

## Context
Every project is treated as equally urgent, so every conflict escalates to the top.

## Decision
Executives publish one Portfolio Rank per month, no ties, WSJF as input. In a conflict the higher rank wins by default. Exceptions go through Resource Council with a recorded reason.

## Consequences
Most decisions are made by the system. Rank must be communicated and accepted before go-live.
