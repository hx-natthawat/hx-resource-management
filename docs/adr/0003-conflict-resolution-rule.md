# ADR-003: Conflict resolution rule

## Status

Proposed. Issue #3.

## Context

ทุกโครงการถูกมองว่าด่วนเท่ากัน ทำให้ conflict ไหลขึ้นมาที่ผู้บริหารสูงสุดทุกครั้ง

Options considered: one Portfolio Rank plus WSJF; case-by-case escalation to the CEO (status quo); WSJF score alone.

## Decision

ผู้บริหารกำหนด Portfolio Rank เดือนละครั้ง ไม่มีสองโครงการอันดับเท่ากัน ใช้ WSJF เป็นข้อมูลประกอบ เมื่อเกิด conflict โครงการ Rank สูงกว่าได้คนก่อนโดยอัตโนมัติ การยกเว้นต้องผ่าน Resource Council พร้อมบันทึกเหตุผล

## Consequences

การตัดสินส่วนใหญ่เกิดที่ระบบ แต่ต้องมีการสื่อสาร Rank ให้ผู้บริหารทุกคนยอมรับก่อนใช้งาน ซึ่ง PMI ระบุว่าเป็นเงื่อนไขสำคัญที่สุด
